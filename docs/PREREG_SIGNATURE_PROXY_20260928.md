## Two explicitly labeled proxies
1. Oncotype-like *formula proxy*: map all 16 published cancer genes by Entrez ID (including CTSV/CTSL2 alias), omit the five reference genes *as genefu does*. Per gene, transform z-scores by the training-patient min and max to [0,15], then apply to test patients and clip test values to [0,15] using the training bounds. Use genefu's published groups: GRB7=max(8, 0.9 GRB7+0.1 ERBB2); ER=(0.8 ESR1+1.2 PGR+BCL2+SCUBE2)/4; proliferation=max(6.5, mean(BIRC5,MKI67,MYBL2,CCNB1,AURKA)); invasion=mean(CTSV,MMP11); risk = .47 GRB7 - .34 ER + 1.04 proliferation + .10 invasion + .05 CD68 - .08 GSTM1 - .07 BAG1. This continuous unscaled risk is used for C-index (no marketed 0-100 score or cutoffs). Cohort-derived scaling is only a proxy, not lab calibration.
2. MammaPrint-like *incomplete centroid proxy*: genefu's 70-probe average-good-prognosis template has 14 probes without Entrez ID; among non-null IDs several are duplicate probes. Map 52 unique non-null IDs present in METABRIC. Collapse duplicate template rows to a mean centroid value per Entrez ID, and collapse duplicate matrix rows to a mean expression value per ID. Per test patient, risk = negative Spearman correlation between that patient's z-score vector and the 52-value good-prognosis centroid. No marketed score or threshold. Report 52/70 unique-ID coverage AND 56/70 mappable probes; missing 14 cannot be inferred from names.
