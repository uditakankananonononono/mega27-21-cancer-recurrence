## Common protocol
Event-stratified 5-fold CV, seed 0; out-of-fold (OOF) risk scores; Harrell C-index (lifelines). Base model: penalized Cox (lifelines CoxPHFitter penalizer 0.1; features standardized on training folds) on clinical + expression. Gates are descriptive pass/fail, set now.

## Directions (all EXTENDS)
X1 Random survival forest (scikit-survival, 200 trees, min_samples_leaf 15) vs Cox, 3 CV repeats (seeds 0-2). EXTENDS XGBSurv benchmark. Gate: RSF mean C >= Cox mean C + 0.01.
X2 Age strata (<=50, 51-65, >65) OOF C-index of base model. EXTENDS (no age cut exists). Gate: every stratum C >= overall C - 0.05.
X3 Claudin-subtype strata (Basal, Her2, LumA, LumB, Normal, claudin-low) OOF C-index, with n and events per stratum; strata with <30 events reported but not gated. EXTENDS treatment_arms_erpos. Gate: every stratum with >=30 events has C >= overall C - 0.05.
X4 Landmark at 36 months: patients event-free and under follow-up at 36 months, recurrence after landmark; base model retrained in CV on that cohort. EXTENDS run_earlylate.py (related, not identical). Gate: C >= 0.60.
X5 Bootstrap optimism correction (200 bootstraps, Harrell): apparent C minus mean optimism for the base model. EXTENDS (no optimism correction exists). Gate: optimism <= 0.02.
X6 Clinical drop-one ablation: remove each of 5 numeric clinical variables (age, size, grade, nodes, NPI) and each categorical group, report delta C (OOF). EXTENDS. No gate; descriptive.
X7 Add binary mutation features (genes mutated in >=3% of patients) to base model. EXTENDS. Gate: mean delta C >= +0.005 over 3 repeats. Limitation: absence of a call is treated as unmutated (sequencing status not modeled).
X8 Split conformal (alpha 0.1) for 5-year recurrence (patients censored before 5 years excluded, n reported): logistic model on base features, calibration split 30%. EXTENDS. Gate: marginal coverage in [0.87, 0.93]; subgroup coverage by ER status and by subtype reported, with the largest deviation.
X9 Missing-data sensitivity: base model with median imputation (existing pipeline) vs complete-case vs IterativeImputer; report per-variable missingness. EXTENDS. Gate: imputation choice changes OOF C by <= 0.01.
X10 Proportional-hazards diagnostics (lifelines Schoenfeld test, clinical covariates) and stratified Cox refit (stratify on the worst violator) OOF C. EXTENDS. Gate: reported only; flags violators at p < 0.05 (Bonferroni over 17).
